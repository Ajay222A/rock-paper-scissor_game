# rock-paper-scissor_game
Rock Paper Scissors game built in Python, where players compete against a randomly generated computer choice.

## 🎮 How to Play
- Run the program
- Choose:
  1 - Rock  
  2 - Paper  
  3 - Scissors  
- The computer will randomly select its move
- The winner is displayed after each round

## 🛠️ Technologies Used
- Python
- random module

## 🚀 How to Run
```bash
python rock-paper-scissor.py
